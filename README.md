
# API de Filmes

## Descrição
Projeto desenvolvido com Python, Django e Django REST Framework para trabalhar com filmes e gêneros.

## Tecnologias utilizadas
- Python
- Django
- Django REST Framework
- SQLite

## Estrutura do projeto
- `manage.py`: executa comandos do Django.
- `filmes/`: contém os arquivos da aplicação.
- `projeto4/`: contém as configurações do projeto.
- `base_filmes.csv`: arquivo com dados dos filmes.
- `importarDados.py`: script de importação de dados.

## Como executar
1. Instale as dependências do projeto.
2. Execute `python manage.py migrate`.
3. Execute `python manage.py runserver`.
